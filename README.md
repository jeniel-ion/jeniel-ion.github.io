# Jeniel Shah — Security Engineer Portfolio

Clean hacker-retro site. Plain readable HTML, CSS, JavaScript.

## Run
python -m http.server 4321 → http://localhost:4321

## Edit (readable files, full names, no abbreviations)
- site-content.js — profile, statistics, about, skills, experience
- disclosure-records.js — NCIIPC, United Nations, Gynzy hall of fame
- security-collections.js — builds, certifications, writeups, audits, ticker
- posts/*.md — writeup articles, add entry in security-collections.js

## Deploy
1. GitHub → new repo `jeniel-ion.github.io` (public)
2. Copy all files here into it, push.
3. Settings → Pages → Deploy from branch → main, root.
4. Live at https://jeniel-ion.github.io
5. Add resume.pdf (replace placeholder), og-image.png (1200x630).
